1. Accès et connexion

Ouvrez l’application dans votre navigateur (l’URL vous sera communiquée). Vous arrivez sur la page de connexion.

  • Email : saisissez l’adresse fournie par l’administrateur.
  • Mot de passe : saisissez le mot de passe reçu.

Cliquez sur Se connecter. En cas d’erreur, un message s’affiche (identifiants incorrects, champ obligatoire, etc.).

Les identifiants de test vous seront envoyés séparément. Ne les partagez pas en dehors du cadre des tests.

2. Tableau de bord

Après connexion, vous accédez au Tableau de bord (menu Tableau de bord ou page d’accueil).

Contenu affiché

  • Membres : nombre total, actifs, inactifs, décédés, répartition par sexe.
  • Événements : total, à venir, passés, ce mois-ci, par type (messe, célébration, activité).
  • Finances : recettes et dépenses du mois, de l’année, soldes, éventuels graphiques (évolution, répartition).
  • Groupes : nombre total et par type (chorale, catéchisme, mouvement, autre).

Les chiffres sont calculés selon la paroisse de l’utilisateur connecté (sauf pour un super administrateur).

3. Membres

Menu Membres.

Liste des membres

Affiche les membres de la paroisse : nom, prénom, coordonnées, statut, etc. Vous pouvez rechercher, filtrer et consulter le détail d’un membre.

Ajouter un membre

Formulaire pour créer un nouveau membre : nom, prénom, sexe, date de naissance, adresse, téléphone, email, statut (actif, inactif, décédé), etc. Renseignez les champs obligatoires puis enregistrez.

Les actions (voir, modifier, supprimer) dépendent des permissions de votre compte. Si un bouton n’apparaît pas, vous n’avez pas le droit d’effectuer l’action.

4. Sacrements

Menu Sacrements. Sous-menus selon vos droits :

  • Baptêmes
  • Confirmations
  • Communions
  • Mariages
  • Obsèques

Chaque section liste les actes du type concerné. Vous pouvez ajouter, modifier et consulter les enregistrements selon vos permissions.

5. Événements

Menu Événements.

Options

  • Tous les événements : liste complète.
  • Messes / Célébrations / Activités : filtres par type.
  • Créer un événement : formulaire (date, heure, type, lieu, description, etc.).

6. Groupes

Menu Groupes.

  • Tous les groupes : liste des groupes (chorale, catéchisme, mouvement, autre).
  • Ajouter un groupe : création (nom, type, description, etc.).

7. Finances

Menu Finances — sous-menus principaux :

Recettes

  • Toutes les recettes : liste avec dates, montants, catégories.
  • Ajouter une recette : date, montant, catégorie/type, libellé, etc.

Dépenses

  • Toutes les dépenses : liste des dépenses.
  • Ajouter une dépense : date, montant, catégorie (fixe, variable, exceptionnelle), libellé.

Rapports

  • Générer un rapport : création d’un rapport financier sur une période.
  • Rapports enregistrés : liste des rapports déjà générés.
  • Rapport Quête ordinaire : rapport des quêtes, avec possibilité d’impression / PDF.
  • Rapport Subvention Popote : rapport pour la subvention « Popote » (impression / PDF).
  • Rapport Charges fixes : synthèse des charges fixes.
  • Statistiques : vues statistiques sur les finances.

Paramètres (Finances)

  • Catégories recettes : gestion des catégories de recettes.
  • Types recettes : gestion des types de recettes.

8. Paroisses

Visible uniquement si votre compte a la permission Gérer les paroisses. Menu Paroisses.

  • Liste des paroisses : consulter et gérer les paroisses.
  • Ajouter une paroisse : créer une nouvelle paroisse (nom, adresse, etc.).

9. Gestion utilisateur

Visible si vous avez l’un des droits : gérer les utilisateurs, les rôles ou les permissions. Menu Gestion utilisateur.

  • Utilisateurs : liste des comptes, ajout, modification, désactivation. Association à une paroisse et à des rôles.
  • Rôles : création et modification des rôles (ex. : secrétaire, trésorier, admin).
  • Permissions : liste des permissions (ex. : view_members, create_events, manage_users) et attribution aux rôles.

10. Configuration

Menu Configuration.

Paramètres généraux

Page regroupant les options de personnalisation de l’application, par exemple :

  • Nom et titre de la paroisse, logo.
  • Apparence de la page de connexion (image de fond, couleurs).
  • Loader (écran de chargement) : activer/désactiver, durée minimale d’affichage, style (logo + spinner, logo seul, etc.), position.
  • Couleurs du thème (couleur primaire, etc.).

Les modifications sont enregistrées via le bouton prévu sur la page. Certaines options peuvent être regroupées en « Enregistrer tout » ou par section.

Si vous avez le droit de gérer les paroisses, un lien vers Paroisses peut aussi apparaître dans cette section.

11. Mon profil

En haut à droite, cliquez sur votre nom (ou avatar) pour ouvrir le menu utilisateur, puis Mon profil.

  • Modifier le profil : nom, email, etc.
  • Changer le mot de passe : mot de passe actuel, nouveau mot de passe, confirmation.

Utilisez Déconnexion dans ce même menu pour quitter l’application en toute sécurité.

12. Conseils pour les tests

  • Testez d’abord la connexion avec les identifiants fournis.
  • Parcourez le tableau de bord et vérifiez que les chiffres correspondent à ce que vous attendez (ou à des données de test).
  • Pour chaque menu auquel vous avez accès : ouvrez les listes, créez un enregistrement de test, modifiez-le, puis supprimez-le si possible (en respectant les messages de confirmation).
  • Vérifiez les formulaires : champs obligatoires, formats (email, téléphone, dates), messages d’erreur.
  • Testez les rapports financiers (quête, Popote, charges fixes) : génération, impression, export PDF si disponible.
  • Si vous avez accès à la Configuration, testez le changement de logo, couleurs et loader, puis rechargez la page pour vérifier la prise en compte.
  • Sur mobile ou tablette, ouvrez le menu via l’icône hamburger (trois barres) en haut à gauche.
Remarque : les droits affichés (menus et boutons) dépendent de votre rôle. Si une section n’apparaît pas, c’est qu’elle n’est pas autorisée pour votre compte. Pour tester d’autres rôles, demandez des comptes supplémentaires à l’administrateur.
